# 音乐生成器 - 移动端适配设计文档

> **版本：** 1.0
> **更新日期：** 2026-05-29
> **状态：** 设计完成，待实现

---

## 1. 设计目标

将现有 Web 端音乐生成器应用适配到移动端（手机竖屏），提供流畅的触控操作体验。

**响应式断点：**
- ≤768px：移动端布局
- >768px：桌面端布局（保持现有设计）

---

## 2. 移动端导航系统

### 2.1 底部 Tab Bar

**Tab 顺序：** 音乐 → 翻唱 → 播放器 → 歌词 → 我的

**播放器 Tab 特殊样式：**
- 位于中间位置（第3个）
- 图标尺寸比其他 Tab 大 30%
- 播放时有呼吸动效（脉冲光效）
- 颜色/样式与其他 Tab 区分

**Tab Bar 规格：**
- 高度：64px（+ Safe Area）
- 图标尺寸：主图标 28px，播放器图标 36px
- 标签字号：10px
- 背景：毛玻璃效果（backdrop-blur）
- 边框：顶部 1px 细线

### 2.2 Header（移动端）

**元素：** Logo + 标题（Music Master）
- 高度：56px
- 不含 API Key、主题切换、风格选择（这些收到"我的"抽屉）

---

## 3. 页面结构

### 3.1 音乐页面（Music）

- 单列垂直布局
- 歌曲描述输入框
- 歌词输入框（可折叠）
- 纯音乐开关
- 音频设置（格式、采样率、比特率）
- 生成按钮（渐变背景）
- 生成过程中：全屏遮罩 + 加载动画

### 3.2 翻唱页面（Cover）

- 文件上传区（点击/拖拽）
- URL 输入区
- 预处理按钮
- Feature ID 显示
- 提取歌词显示/编辑

### 3.3 播放器页面（Player）

- 完整独立页面
- 保留底部 Tab Bar
- 音频波形/进度条
- 播放控制（上一首/播放暂停/下一首）
- 当前播放信息（标题、时长）
- 播放列表入口

### 3.4 歌词页面（Lyrics）

以抽屉形式呈现，包含两个切换视图：

**Tab 1 - 歌词编辑：**
- 描述输入框
- 生成歌词按钮
- 生成的歌词显示
- "应用到音乐生成"按钮

**Tab 2 - 示例：**
- 结构标签参考
- 示例歌词展示

### 3.5 我的页面（Me）

**"我的"抽屉内容：**
- API Key 设置
- 主题切换（明/暗）
- 风格选择（温暖自然/清新自然/赛博朋克）
- 生成历史（之前生成的音乐列表）

---

## 4. 交互反馈设计

### 4.1 报错信息

**形式：** 顶部横幅（Toast）

**规格：**
- 位置：顶部状态栏下方
- 背景：红色半透明（#ef4444 / 90% opacity）
- 文字：白色
- 右上角关闭按钮
- 自动消失：3秒后滑动消失
- 可手动滑动关闭

### 4.2 加载状态

**形式：** 全屏遮罩 + 动画

**规格：**
- 背景：黑色半透明遮罩（50% opacity）
- 中央：加载动画 + "生成中，请稍候..." 文字
- 背景内容：不可操作

### 4.3 按钮点击反馈

- 触控时有缩放动画（scale: 0.96 → 1）
- 涟漪效果（可选）

---

## 5. 触控友好设计

### 5.1 触控目标尺寸

- 最小触控区域：44px × 44px
- 按钮内边距：至少 12px
- 列表项高度：≥ 56px

### 5.2 字体大小

- 正文：15px
- 辅助文字：13px
- 按钮文字：14px（粗体）

### 5.3 间距

- 页面内边距：16px
- 卡片间距：16px
- 元素间距：12px

---

## 6. 现有组件适配

### 6.1 MusicGenerator

桌面端：作为 2/3 宽的主卡片
移动端：单列全宽布局

### 6.2 CoverProcessor

桌面端：2/3 宽主卡片
移动端：单列全宽布局

### 6.3 LyricsPanel / LyricsExample

桌面端：并排显示在右侧
移动端：合并为一个抽屉，通过内部 Tab 切换

### 6.4 AudioResultPanel

桌面端：悬浮面板
移动端：作为播放器 Tab 的完整页面

---

## 7. 技术实现要点

### 7.1 响应式检测

```typescript
const isMobile = window.innerWidth <= 768;
```

### 7.2 条件渲染

```tsx
{/* 移动端 */}
{isMobile && <MobileTabBar />}

/{/* 桌面端 */}
{!isMobile && <DesktopSidebar />}
```

### 7.3 播放器突出显示

通过 CSS 或动画库实现：
- 呼吸动效：CSS animation + keyframes
- 尺寸差异：CSS transform: scale()

## 8. 设计验收标准

- [ ] 768px 断点正确触发移动端布局
- [ ] 底部 Tab Bar 5 个 Tab 正确显示，播放器居中且样式突出
- [ ] 播放器有呼吸动效
- [ ] 移动端 Header 仅显示 Logo + 标题
- [ ] 歌词抽屉内可切换编辑/示例视图
- [ ] 报错信息显示为顶部横幅并可滑动消失
- [ ] 加载状态为全屏遮罩
- [ ] 所有触控目标尺寸 ≥ 44px
- [ ] 桌面端保持现有设计不变
